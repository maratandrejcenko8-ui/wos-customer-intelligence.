Получите отчёт за несколько минут

Без регистрации
  1. Выберите площадкуWildberries или Ozon
  2. Вставьте ключ APIТолько чтение, мы его не сохраняем
  3. Укажите периодДо 12 месяцев

🔒 Ключ используется один раз, чтобы загрузить отзывы, и не сохраняется на сервере. Создайте отдельный токен «только чтение» и удалите его после получения отчёта.

Где взять ключ

Wildberries. Личный кабинет → Профиль → Настройки → Доступ к API → создать токен. Категория «Вопросы и отзывы», тип доступа «Только чтение».

Ozon. Личный кабинет продавца → Настройки → API-ключи → добавить ключ с доступом на чтение. Client-Id указан там же. Загрузка отзывов через API доступна при подписке Premium Plus.

Implementation

От источников
к понятным решениям

Внедрение начинается с согласования задачи и доступных данных. Не нужно подключать все источники сразу.

01

Определяем задачу

Выбираем категорию, товары и вопросы, на которые бренд хочет получить ответы.

02

Подключаем источники

Отзывы: публичные страницы, разрешённые API или выгрузки продавца. Переписки: согласованный экспорт или интеграция с доступным каналом, например Telegram или CRM.

03

Согласуем доступ и безопасность

Бренд подтверждает право передавать данные. API-ключи и токены передаются безопасно и хранятся на сервере, не в браузере и не в публичном коде.

04

Проводим пилот

Проверяем качество данных, формируем первый отчёт и согласуем, какие выводы действительно полезны.

05

Переходим к регулярной аналитике

После успешного пилота определяем частоту обновления, автоматизацию и формат дальнейшей работы.

Что понадобится от бренда

  • Название бренда и список товаров или категорий.
  • Ссылки на публичные карточки и источники отзывов.
  • При необходимости — доступ к официальному API или выгрузка из кабинета продавца.
  • Для переписок — согласованный экспорт или разрешённый доступ к системе, где они хранятся.
  • Контакт ответственного за проект и описание задачи.

Набор данных зависит от источника. Наличие Telegram-канала не означает доступ к личным сообщениям; подключение частных обращений требует отдельного разрешённого способа доступа.
